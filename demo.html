Entropy Minimization without Model Collapse: Mitigating Prediction Bias in Medical Imaging

Tim Nielen*, Sameer Ambekar*, Johannes Kiechle, Daniel M. Lang#, Julia A. Schnabel#

* Shared first authorship  ·  # Shared last authorship

How our method treats every sample during unsupervised adaptation

Each band is one predicted class, and its height shows that class’s share of the total weight in each batch. Entropy Minimization gives every sample the same weight, so the most frequently predicted class takes over the update until the model collapses. DSBR divides each sample’s weight by how often its class is predicted, so every class keeps a say.

Entropy Minimization

Weight of one sample, by predicted class

Every sample has a weight of 1, whatever its class, so each class’s share of the weight simply follows the predictions.

Distribution Shift Bias Reduction (DSBR)

Share of the total weight, by predicted class (10-batch average)

Weight of one sample, by predicted class

A tall bar marks a class that the model currently predicts rarely. DSBR raises its weight so that it is not drowned out.

Both methods adapt the same small synthetic model on identical batches, using the update rules from the paper’s code. We report model collapse when one class receives at least 95% of the predictions on held-out samples. DSBR uses a decay of α = 0.9.
