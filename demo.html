Where the update’s weight goes

Each band is one predicted class, and its height is that class’s share of the total weight in each batch. Entropy Minimization gives every sample the same weight, so the most-predicted class takes over the update until the model collapses. DSBR divides each sample’s weight by how often its class is predicted, so every class keeps a say.

Both methods adapt the same small synthetic model live in your browser, on identical batches, using the update rules from the paper’s code. We call it a collapse when one class receives at least 95% of predictions on held-out samples. DSBR uses a decay of α = 0.9.
